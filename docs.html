Nabhya API

Integrate deep-learning vegetation intelligence directly into your drone applications.

Endpoint

Generate near-NDVI heatmaps, structural intelligence, and stress zone detection from standard RGB imagery.

POST https://api.nabhya.tech/analyze

Authentication

Authenticate your requests by including your API key in the headers. Contact sales to receive a key.

X-Nabhya-Key: your_api_key_here

Request Format

Submit an image via multipart/form-data.

Parameter Type Description
file File The RGB image file (PNG, JPG, TIFF). Max size: 10MB.

Response Schema

Examples

Python (Requests)

import requests

url = "https://api.nabhya.tech/analyze"
headers = {"X-Nabhya-Key": "your_api_key_here"}

with open("farm_aerial.jpg", "rb") as f:
    files = {"file": f}
    response = requests.post(url, headers=headers, files=files)

print(response.json()["vegetation_intelligence"])

cURL

curl -X POST https://api.nabhya.tech/analyze \
  -H "X-Nabhya-Key: your_api_key_here" \
  -F "file=@farm_aerial.jpg"
